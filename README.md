# Where? · Playa Soledad

Landing de Where? para el plan a Playa Soledad, Chocó.

Stack: Next.js 15 (App Router) · TypeScript · Tailwind v4 · GSAP + ScrollTrigger · Lenis · Swiper

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

- Textos, contacto y WhatsApp: `src/data/site.ts`
- Fotos y videos: `public/media/` (si reemplazas un archivo, conserva su nombre)
- Dominio para Open Graph: variable `NEXT_PUBLIC_SITE_URL`
